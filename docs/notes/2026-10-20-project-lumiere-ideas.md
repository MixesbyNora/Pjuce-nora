Ideas for PROJECT LUMIERE  
  
So project Lumiere is consisting of two separate plug-ins built on the same framework. The first one which currently is called Lumiere is our tube version of our tube compressor. The second one is gonna be a solid state compressor. The goal with these compressors is to be the first true showcase of what the company name truly stands for. Beyond analog. Time and time again I see plug-in developers not taking advantage of the fact that we’re in a DSP environment we’re not limited by analog hardware and physical audio hardware. So the goal of these is to be the first true showcase of this idea that we can do so much more with the tools we have then we’re actually doing. So the basic concept for project Lumiere let’s use the tube version as an example is you will be able to choose different tubes for the saturation circuit. You will also be able to change different transformer models so you can change the input transformers model and you could change the output transformers model separately and you could change the transformers and the tubes both separate separately, you can even turn the tubes fully off or turn the transformers fully off or do both there’s no limitation. Same thing goes for the actual compression type or characteristic. There will be multiple types of strictly compression types that you can change that you can interchange in tandem with all the saturation types. So in essence, this is basically you can almost change you can literally actually you can literally change every component of the compressor. Now in the real world, this would make no sense. If you have a very new style compressor, let’s say a fair child. Well, you can’t really take out all the tubes, even if you took out, let’s just say you took out some of the tubes that happened after compression after the makeup gain well at the end of the day you’re using a remote cut off tubes for the compression itself. same thing goes to the transformers they serve a purpose. They’re not just there for color. That’s just a side effect of a transformer and there’s even transformers that are basically colorless so the idea here is giving the user full control over the sound of the compressor. Same goes for the graphics interface there will be a analog version. There will be a modern version. There will be a modern version with graphics to where there’s like a graph that you could see how much compressions being done visually the options there’s gonna be tons of options that are very accessible and easy to use. all of this information is exactly true. Also for the solid state version of this compressor. The solid state version is gonna be also amazing. You could literally have. Let’s say the output transformer from a blue stripe 1176, the input transformer let’s say from SSLG bus compressor you could have the VCA’s from a SSL channel compressor, you could have the transistors from a distressor, and you could you could even add op-amps into the circuit or replace the main compression characteristic with a amp style you could literally make a Frankenstein compressor of your dreams. Also, there will be a “box tone” control where you can switch between different frequency response curves.
