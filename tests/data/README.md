# Transformer audio reference

`TransformerAudioReference.bin` was captured from the unchanged transformer at
base commit `fef154c`, before the development-voicing refactor. It contains two
channels of 8,192 little-endian float32 samples (channel-major), generated by the
`[voicing-reference]` test with a 73 Hz, -3 dBFS sine at 48 kHz, including Amount
and Out automation. It is the macOS arm64 Debug reference for exact regression
comparison; do not regenerate it to make a changed implementation pass.

`LUMIERE_TRANSFORMER_REFERENCE_EXPORT` is the explicit capture mechanism in the
test. Use it only when intentionally establishing a reviewed new baseline.
